# Gen Alpha Translator 
#### A simple translator to convert Gen Alpha's new slang into text readable by old people
##### By Sam Rohrbach

****

This project is also on my website, [samrohrbach.space](https://samrohrbach.space). 

Have you ever talked to a gen Alpha "iPad kid" and heard sentences like "*Skibidi sigma Ohio rizz cranking 90s with the level 10 gyatt*" and were completely baffled? So have I. 

Have you ever felt completely lost in those conversations? So have I. 

Have you wished there was a translator for this new slang? So have I. So I made this translator. 

****

For the full list of words translated, look at SkibidiRizz.js in the root directory. To add new words or change existing ones, create an issue or submit a pull request.
